# AgentTrap 발표 자료

- `output/AgentTrap-발표-최종.pptx`: 최신 발표본. Daytona·Nosana·AI Builders 공식 로고를 포함한 7장, 3분 발표용입니다. 각 슬라이드 발표자 노트에도 대본을 넣었습니다.
- `발표대본.md`: 시간대별 대본과 데모 장애 대응 문구입니다.
- `output/AgentTrap-데모.html`: 인터넷 없이 파일을 브라우저로 열어 사용할 수 있는 독립 데모입니다. 프로젝트 Streamlit UI와 별개입니다.

## 권장 데모 순서

1. 실제 기록 재생에서 Qwen 정상 입력을 선택하고 기록 재생을 누릅니다.
2. Qwen 삭제 공격 방어를 선택하고 동일한 필수 요약과 읽기 기록을 설명합니다.
3. 시뮬레이션에서 삭제 시도와 차단 예시를 보여줍니다. 실제 공격 성공 기록이 아닌 고정 예시라고 설명합니다.
4. 재도전 버튼으로 결과를 초기화합니다.
5. 시간이 남으면 JSON 오류 기록을 재생하고 실행 오류는 공격 승리가 아님을 설명합니다.

실제 기록은 `docs/evidence/2026-10-18/`의 JSON을 HTML에 포함했습니다. 재생은 새 API 요청을 하지 않으며, 화면은 REPLAY 또는 MOCK을 명시합니다. 입력 문구를 바꿔도 시뮬레이션 결과는 고정 예시입니다.

## 로컬 서버로 열기

저장소 루트에서 다음 명령을 실행한 뒤 브라우저에서 `http://127.0.0.1:8765/AgentTrap-데모.html`을 엽니다.

```sh
.venv/bin/python -m http.server 8765 --bind 127.0.0.1 --directory docs/presentation/output
```

발표 전 목표 GLM의 연결 상태와 UI 통합 여부가 바뀌었다면 슬라이드 6과 해당 대본을 갱신하세요. 기존 Qwen 실행 기록은 GLM의 검증 근거가 아닙니다.
