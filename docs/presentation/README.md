## 최신 발표의 데모 순서

1. `http://127.0.0.1:8501/`에서 미리보기를 끄고 현재 레벨을 보여줍니다.
2. 공격 문구를 실행하고 실제 승패와 도구 시도·차단 여부를 설명합니다.
3. 공격에 성공하면 다음 레벨이 해금됩니다. 실패하면 Retry로 같은 컨테이너에서 재도전합니다.
4. 다음 레벨 버튼을 누르면 기존 컨테이너를 삭제한 뒤 이동합니다. 만료·오류 이후에는 새 컨테이너를 사용합니다.
5. 서비스가 지연되면 실제 GLM 기록 화면을 열고 이전 실행 기록임을 설명합니다. 실제 3단계 전체 클리어는 미검증입니다.

테스트 범위는 [자동 테스트 요약](../TEST_SUMMARY.md)을 확인하세요. 중간 검증 89개와 최종 90개를 구분합니다.

## 기존 오프라인 데모 순서

1. 실제 기록 재생에서 Qwen 정상 입력을 선택하고 기록 재생을 누릅니다.
2. Qwen 삭제 공격 방어를 선택하고 동일한 필수 요약과 읽기 기록을 설명합니다.
3. 시뮬레이션에서 삭제 시도와 차단 예시를 보여줍니다. 실제 공격 성공 기록이 아닌 고정 예시라고 설명합니다.
4. 재도전 버튼으로 결과를 초기화합니다.
5. 시간이 남으면 JSON 오류 기록을 재생하고 실행 오류는 공격 승리가 아님을 설명합니다.

실제 기록은 `docs/evidence/2026-10-18/`의 JSON을 HTML에 포함했습니다. 재생은 새 API 요청을 하지 않으며, 화면은 REPLAY 또는 MOCK을 명시합니다. 입력 문구를 바꿔도 시뮬레이션 결과는 고정 예시입니다.

## 로컬 서버로 열기

저장소 루트에서 다음 명령을 실행한 뒤 브라우저에서 `http://127.0.0.1:8765/AgentTrap-데모.html`을 엽니다.

```sh
.venv/bin/python -m http.server 8765 --bind 127.0.0.1 --directory docs/presentation/output
```

현재 구현 설명은 main `8cbbb26` 기준입니다. 4단계는 향후 발전 방향이며, 실제 메일·문서·고객지원 AI와의 서비스별 연결 및 검증은 아직 구현하지 않았습니다. GLM 연결·UI 및 컨테이너 재사용의 실제 기록을 반영했습니다. 기존 오프라인 HTML은 Qwen 기록·Mock 체험용으로 유지하며 GLM·레벨링의 실시간 데모와 구분합니다.
