# 이 프로젝트에 사용할 스킬

`ask-matt`로 현재 상황을 분류했다. 요구사항이 확정된 해커톤이므로 다음 흐름을 사용한다.

| 스킬 | 사용 시점 |
| --- | --- |
| `tdd` | `run_attack`, Nosana/Daytona 경계의 동작을 실패 테스트 → 최소 구현으로 완성 |
| `code-review` | 기준 커밋 `03ff8b7`부터의 변경을 규칙과 요구사항 두 관점에서 점검 |
| `diagnosing-bugs` | 바로 원인이 보이지 않는 실행/회귀 오류가 생겼을 때 재현 명령부터 확보 |
| `wizard` | 사용자가 API 키를 발급·입력해야 하는 절차를 자동 안내할 필요가 있을 때 |
| `handoff` | 다른 도구나 동료로 맥락을 옮길 때. 현재는 HANDOFF.md와 친구용 프롬프트 사용 |

설치된 로컬 스킬을 사용한다. 추가 설치나 긴 인터뷰·티켓 생성 흐름은 현재 구현의 선행 조건으로 두지 않는다. GitHub와 확정 요구사항은 `docs/agents/issue-tracker.md`, `docs/specs/runtime.md`에 기록한다.
